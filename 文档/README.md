## 根目录保留规则

根目录只保留需要频繁恢复或持续更新的四个稳定入口：

- `当前开发状态.md`
- `主控任务台账.md`
- `V1需求验收矩阵.md`
- `集中验收待办.md`

新增长期使用说明应放入 `01-使用指南`；产品级规格和计划放入 `02-产品规格与计划`；实施前设计放入 `03-实施契约`。一次性任务和证据不得重新堆回根目录。

## 状态判定原则

- 当前结论以根目录四个稳定入口及产品总规格为准；
- “任务包”描述计划做什么，不证明已经完成；
- “交付记录”证明已实现和做过哪些基本检查，不自动等于完整验收；
- “验收记录”要结合日期和最终矩阵阅读，早期阶段结论可能已被后续结果取代；
- Claude 资料是 2026-08-29 的历史交接资产，不能覆盖当前 `AGENTS.md` 和当前开发状态。
