# P6-X2 报告导出前端任务包

主控已确认 P6-X1/r2 与 X1M、V1-T3/r2 均通过审查，现派发 P6-X2/r1。Backend/Runner 的 P6-L1 加载在 DevOps 独立进行；本包只用隔离 API，不依赖正式服务，也不向 DevOps 发送消息。

## 范围

Frontend 独占 `frontend/src/api/reports.ts`、`frontend/src/views/reports/ReportDetailView.vue`、必要独立导出 helper/类型与测试；独占证据 `.codex-validation/p6-x2/`，交付 `文档/05-交付记录/P6-X2报告导出前端交付.md`。不改已验收报告分页/筛选语义、T3、Backend、Runner、全局文档或正式服务。使用 Sol/xhigh；完成后结束，由主控拉取，不使用任务消息工具。

## 行为

报告详情提供 Markdown 与 HTML 两种明确下载操作。通过已有带认证的 http 客户端 GET `/reports/{encodeURIComponent(runId)}/export?format=markdown|html`，responseType blob；后端收集完整报告，不能从页面当前分页自行拼装。按钮说明为完整报告下载，无需跳转或调用业务写接口。

仅显式点击发起下载。下载绑定当时的 Run ID、格式与详情上下文；重复点击在请求完成前禁用，刷新、切换 Run、离开页面、重新登录后旧响应不得触发下载、错误弹窗或覆盖新 loading。成功使用 Blob 对象 URL 和安全文件名下载，撤销自己创建的 URL、清理临时 anchor；不要把 Bearer Token 放入 URL，不把 HTML 通过 v-html 或新窗口执行。

响应必须校验格式匹配的 Content-Type，非报告 JSON/错误正文不保存为成功附件。安全处理 Content-Disposition，拒绝路径/控制字符等，必要时使用由固定前缀、受控 Run 标识与格式扩展名组成的回退文件名。保留身份拦截器的 401 行为。413 上限、409 快照变化或编码问题、404 无访问权、网络失败均显示可理解错误，不自动重试；Blob 错误正文有界解析，保留安全的后端 message，不展示原始正文。

归档资产的可授权历史报告仍允许导出；报告不可访问或详情未就绪时不提供误导性成功入口。非终态提示保留后端快照语义，不声称永久最终结果。不要混入 PDF、后台导出任务、外部分享等范围。

## 验收

真实 Chrome 受控 API 验证两格式：实际 GET 参数、Authorization 传递、下载文件名/字节内容和 Unicode；全报告与页面当前页独立；重复点击仅一次请求；延迟成功/失败后换 Run、刷新与卸载，旧结果不下载/弹错/干扰当前 loading；401/404/409/413、JSON 伪成功和恶意附件名；对象 URL 与临时资源清理。

保留 P6-U1 的 30 项回归、类型检查和独立构建。新增测试应断言真实下载与响应内容，不能只检查按钮存在。报告记录修改文件指纹、命令、结果、截图及未进行正式联调的边界。主控随后统一加载并使用真实历史报告只读验收。
