# Phase 6 报告导出实施契约

2026-09-10 主控设计。依据总规格第 74～75 节；本文件不是完成证明，也不向运行中的任务追加范围。报告读取接口经主控冻结后，可以独立实现新增导出端点；前端接入必须等待导出接口审查。正式加载等待本批报告与重试代码统一验收。

## 行为与数据来源

为统一报告提供 Markdown 和 HTML 下载。建议 `GET /api/v1/reports/{run_id}/export?format=markdown|html`，沿用报告详情的用户与项目授权，包含归档项目的授权历史。两种格式都从既有报告公开模型生成，不遍历 ORM 全部字段，不读取目标系统、MinIO 正文或当前 Secret，不触发 Run、AI、修复或审核。

导出包括生成时间、Run 原始状态与计数、Case 实际分组计数及成功率口径、锁定版本和当前资产元数据区别、环境与 Runner 引用、全部 Case/Step 结果、Evidence 元数据、已有 AI 审计引用。请求或提取结果未持久化时保留“未记录”，不从当前配置重建。保留平台失败但步骤成功、取消、跳过、超时、空分母等差异。

不得仅导出详情接口的首屏 20/50 条后声称完整。使用报告服务的授权查询与分页语义，批量读取并复用其脱敏映射；导出快照的数据库事务保持一致，标注导出时刻及正在运行的状态，不承诺未终态报告不可变化。

## 有界执行

同步导出设置明确的行数及 UTF-8 输出字节上限。建议总 Case 不超过 2000、Step 不超过 10000、Evidence 不超过 5000，生成结果不超过 16 MiB；具体常量由实施包交付后主控审核。超过上限应返回稳定的可解释错误，并建议缩小运行规模或使用分页页面查看，不静默截断、不返回标称完整的半份文件。不以流式响应已发送 200 后才发现超限的方式隐藏失败。

查询禁止逐 Case 或 Evidence 的 N+1；不无限积累任意 JSON、原始 AI 内容或证据正文。调用现有有界脱敏，不降低 L1 保护，也不改写数据库历史。

## 文件与内容安全

使用附件 Content-Disposition、明确 charset 和 MIME、nosniff 与私有禁止缓存响应；文件名只包含固定前缀、验证后的 Run 标识和扩展名，不能由标题、错误消息或任意 Header 内容拼接。

HTML 为独立静态文档，所有动态文本经过 HTML 转义，禁止脚本、iframe、表单、事件属性、外部样式/字体/图片及其他自动网络请求。配合文档 CSP，样式仅使用固定内嵌内容；不能把结果正文当作 HTML 插入。Evidence 展示名称、类型、大小、哈希和关联 ID，不内嵌原始 HTML/Trace，也不包含签名 URL 或存储内部地址。

Markdown 将标题、表格与正文中不可信 Markdown/HTML 作为普通文本处理；代码块分隔符不得被任意反引号内容提前闭合。禁止把用户内容直接变成图片或链接。可追溯性依赖 Run/Case/Step/Evidence ID 与受保护应用路径，导出的离线文件本身不能赋予访问权限。

## 前端与验证

报告详情增加明确的两种导出操作，通过现有鉴权 HTTP 客户端下载 Blob，不用带 token 的 URL。显示加载与权限/超限/网络失败提示，不改变报告内容、筛选或执行状态。运行中的报告提示这是当前快照。

后端先交付接口和独立测试，主控审查后再给 Frontend 接入。验证覆盖角色/项目隔离、归档历史、全部分页记录、锁定旧版本、空值和状态口径、恶意 HTML/Markdown/文件名、容量边界及数据库不变；HTML 使用真实 Chrome 打开本地生成文件，确认内容可读、脚本不执行且没有外部请求。Markdown 核对字段和字符转义。最后用正式受保护历史执行只读导出验证，不能重跑旧业务恢复脚本。

AI 可编辑缺陷草稿和 Requirement→Case→Run→Evidence 查询另立任务包；本包不把普通报告导出计为这些功能已实现，也不提交到任何外部缺陷系统。
