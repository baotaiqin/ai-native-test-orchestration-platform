# Phase 6 需求影响与追溯实施契约

主控设计，尚未派发、实现或验收。安排在当前报告/重试批次统一加载和只读联调之后。依据总规格第 15 节、15.1 节，V1 只做确定性关联与影响范围，不引入 V2 的 AI 影响推断或自动修改用例。

## 现状与复用

已有 RequirementVersion、当前版本切换、`/requirements/{id}/diff` 与前端 Diff 展示；已有 RequirementCaseLink、AI 建议接受及手工 Case 创建时的关联记录。继续复用这些入口，不重建版本系统。

当前 Diff 用字符串前缀排除文件头，会漏计正文以 `++` / `--` 开头的变化。主控隔离复现见 `.codex-validation/test_requirement_diff_review.py`。修复时应根据差异结构区分文件头和正文，覆盖相同版本、空内容、插入/删除/替换与多个片段；是否发生变化依据版本实际内容或其可信内容哈希，不能仅依赖展示计数。

现有链接只指向 `test_cases`，其中旧 `case_type=WEB` 不等于独立可执行 `web_cases`。响应和页面须明确资产种类，不能把相同整数 ID 当作同一资产。

## 影响查询

新增只读影响查询，项目权限与 Requirement Diff 保持一致；版本必须属于同一指定 Requirement。响应明确 from/to 的版本 ID、版本号、内容变化事实和关联用例集合。分页参数有界且排序稳定；批量取得资产/版本，不按每条关联新增查询。

当已知基线到目标需求版本的内容发生变化时，关联用例显示 `POSSIBLY_OUTDATED`，含“确定性关联范围，尚未经人工确认实际受影响”的说明。这是单独的影响标记，不覆盖 TestCase/WebCase 的 ACTIVE/ARCHIVED 或版本的 DRAFT/APPROVED 状态，不自动生成、批准或执行新版本。

明确区分用户选择两个需求版本进行比较和链接自身的来源版本比较。没有可靠来源版本的旧链接标记基线未知，不假定它来自 V1，也不从当前版本或创建时间猜测。即使展示选定 Diff 的潜在影响范围，也不能将所选 from_version 写成旧链接真实来源。

仅绑定到某资产、未记录其 CaseVersion 的历史链接，应展示“资产级关联，历史用例版本未记录”。报告中的历史 Run 继续以执行时锁定 CaseVersion 为准；不能使用现在的链接或当前 CaseVersion 构造并不存在的历史需求快照。

## 关联与兼容

支持原 TestCase 与独立 WebCase 的明确目标类型。保持旧 TestCase 链接和 API 语义，扩展时使用独立外键/类型判别并在数据库与服务中校验唯一目标、同项目及版本归属；不能去掉现有外键后仅凭一个不受约束的整数定位所有资产。

新建关联可显式固定 RequirementVersion 和 CaseVersion；AI 接受或手工创建本来已知所创建版本时，在同一业务事务保存精确引用。旧记录缺少的 CaseVersion 保持未知，迁移不得回填为当前版本。原 `source`、`confidence`、relation_type 和创建审计保留。

新增/调整关联必须使用项目写权限并尊重归档门禁；只读角色可查看。移除当前覆盖关系应保留足够审计，避免删除已有 Run 所依赖的历史来源。UI 要求用户显式选择目标资产种类/版本，不能依据同名或数字 ID 自动关联。

## 前端与历史报告

需求详情显示关联资产、已记录来源版本、影响原因、比较版本和跳转入口；用例侧能返回相关需求。基线未知、归档、缺失/无权限、没有变化及未关联分别显示真实状态。页面保留现有 Diff；旧响应晚到不覆盖已切换需求/版本/项目，失败或未知不能显示为“无影响”。

报告中的精确历史引用只有存在可靠持久关系时才展示；资产级当前关系可以单独标注为当前信息，不能并入锁定执行快照。保护 P5-E 的旧 Run、版本、Evidence 与 AI 记录，不通过回填这些正式历史证明新功能。

## 分包与验收

先 Backend 明确迁移及增量 API，完成隔离测试和真实 MySQL 空/非空兼容检查；主控冻结后再派 Frontend。Runner 无需改变执行协议。共享数据库迁移及正式加载由后续独立 DevOps 包负责，不与前端开发相互发消息或等待。

测试至少覆盖：旧链接无版本不被伪造、API/旧 WEB TestCase/独立 WebCase 数字 ID 冲突、跨项目和错误版本拒绝、归档历史可读、相同内容不误判、正文类似 Diff 文件头、多个基线版本、分页完整性与无 N+1、权限、链接与资产状态独立、旧 Run 锁定版本不变。真实 Chrome 展示两个需求版本变化及关联影响，人工新版本仅显式创建，不产生自动 Run/AI 调用。

本文件不允许提前修改产品或执行迁移；实际文件范围、修订号、独占报告和测试资源由主控派发时明确。
