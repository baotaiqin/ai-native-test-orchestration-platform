## 实现摘要

### 完整报告下载

- 报告详情仅在授权详情加载成功后显示“下载完整 Markdown”和“下载完整 HTML”两个显式操作；打开页面不会自动导出。
- 使用已有认证 `http` 客户端调用 `GET /reports/{encodeURIComponent(runId)}/export`，仅传闭合 `format=markdown|html` 参数并使用 `responseType: blob`。
- 导出由后端汇总全部 CaseRun、StepRun 与 Evidence，前端不遍历、拼接或伪装当前页面分页数据。
- 只为导出请求设置有界 `60_000 ms` 超时，不改变全局 `15_000 ms` HTTP 超时，不自动重试，也不调用业务写接口。
- 归档项目的可授权历史详情仍可导出；详情未就绪时不显示下载入口。非终态 Run 明确提示下载内容只是导出时刻快照，后续可能变化。

### 文件与响应安全

- Markdown 只接受 `text/markdown`，HTML 只接受 `text/html`；MIME 不匹配或即使伪装成正确 MIME 的 JSON 对象响应都不会保存为附件。
- `Content-Disposition` 文件名限长且只接受 ASCII 字母、数字、点、下划线、连字符，并强制匹配所选格式扩展名；路径、控制字符、编码路径及错扩展名均降级为固定 `ai-test-report-{安全 Run 标识}.md|.html`。
- 成功响应通过 Blob 对象 URL 和临时 `<a download>` 保存，不执行 HTML、不使用 `v-html`、新窗口或外部 URL；临时 anchor 立即移除，自己创建的对象 URL 在当前任务队列后撤销。
- Blob 错误正文只在不超过 64 KiB 时尝试 JSON 解析，后端 `message` 清理控制字符并限制为 500 字符；超限或非 JSON 正文不解析、不回显原始内容。
- 401 保留共享身份拦截器的 token 清理与登录跳转；404、409、413、格式异常、超时和网络失败均有可理解反馈且不自动重试。

### 请求上下文与身份绑定

- 每次详情读取与导出都以实际 HTTP 拦截器读取的共享 `localStorage` 身份生成同源指纹；导出另锁定请求序号、详情上下文代际、Run ID、格式和已授权详情对象，不再依赖可能滞后的标签页 Pinia 值判断实际请求身份。
- 报告组件监听真实 `storage` 事件；跨标签页登录、退出、清空、详情刷新、Run 变化（含 A→B→A）、身份 A→B→A 和组件卸载都会使旧导出失效并释放当前页面 loading。
- 新身份不会继续使用旧身份加载的详情：完整详情先清空，再同步页面身份并重新调用授权详情接口；身份缺失或无效时清空详情并进入登录流程。
- 迟到成功不能触发下载或成功消息；迟到失败不能弹错；旧请求 `finally` 不能提前结束新上下文或新身份正在进行的 loading。
- 请求完成前两个格式入口均禁用，同步重复点击只能产生一次请求。
- 共享 401 拦截器记录派发 token 与 storage 代际；只有返回 401 的请求仍属于当前实际身份时才清除身份并跳转，旧身份迟到 401 仍正常 reject 给调用方但不改写新会话。
