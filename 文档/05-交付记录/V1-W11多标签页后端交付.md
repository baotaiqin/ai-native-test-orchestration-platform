## 修改

- `backend/app/modules/web_cases/schemas.py`：新增 `NEW_TAB`、`SWITCH_TAB`、`CLOSE_TAB` 三种严格动作资产。
  - `NEW_TAB` 只含 `type/url/value/timeout_ms/failure_policy`；URL 接受合法 http(s) 或合法运行时模板，拒绝相对地址、其他 scheme、凭据 URL、换行及畸形模板。
  - `SWITCH_TAB`、`CLOSE_TAB` 只含 `type/value/timeout_ms/failure_policy`。
  - 别名固定为 `[A-Za-z][A-Za-z0-9_-]{0,63}`；`NEW_TAB` 禁止 `main`，切换或关闭 `main` 仍允许交给 Runner 现场状态机判断。
  - 三种动作使用严格整数 `100..600000` 超时，沿用 `STOP/CONTINUE`。
- `backend/tests/test_web_cases.py`：新增合法/非法形状、别名、URL、预算、额外字段及 Runner 现场状态责任边界测试。
- `backend/tests/test_runs.py`：新增使用 A1 真实登录夹具的隔离 HTTP 闭环，覆盖创建/批准、Run 锁版本、新 current 草稿不漂移、模板上下文、七字段计划、冻结 Runner Web 解析器以及完成报告节点身份。
- `backend/app/modules/runs/service.py` 未修改：现有通用计划生成已自动保留 URL、别名、预算、`failure_policy`、模板上下文，并将不适用字段输出为 `null`。

## 冻结接口

- WebCase DSL 新增 `NEW_TAB`、`SWITCH_TAB`、`CLOSE_TAB`。
- 执行计划继续使用 `schema_version=1` 和 `type/timeout_ms/failure_policy/url/locator/value/key` 七字段；不适用项显式为 `null`。
- `main` 仍表示初始页；未知/重复/已关闭别名、16 页上限及关闭最后一页不在后端伪判成功，继续由 Runner 运行现场受控判定。
- 未修改报告 API、快照语义、Runner 协议、认证、模型、配置、依赖或迁移。
