## 已实现

1. 对齐 A1 冻结契约，新增服务器 Session 退出、本人改密以及用户列表/创建/更新 API；没有增加注册、删除、密码读取或密码重置入口。
2. Auth Store 新增不可复用身份 epoch：登录、`/auth/me` 恢复、跨标签同步、退出、改密和 401 清理都会隔离旧操作；epoch 同时进入 `current_user` 原始存储快照，使既有 I1F/报告 fingerprint 防护继续兼容并可拒绝同 token 文本的 A-B-A 迟到响应。
3. 路由进入受保护页面时以 `/auth/me` 恢复当前用户，缓存 roles 不作为最终 ADMIN 权限。损坏或不完整的持久 JSON 会安全清理并回到未登录；ADMIN 菜单、路由与用户管理函数入口均再次检查已验证的平台角色。
4. 退出先调用 `POST /auth/logout`。成功后只清理发起请求时的身份；失败时由用户明确选择是否“仅本地退出”，并明确提示服务器撤销未确认。并发重新登录后的迟到 logout 不会清掉新身份。
5. 本人改密只提交 `current_password/new_password`，本地确认字段不进入请求。密码空白不 trim，密码不进入持久存储、URL 或日志，身份变化、离开页面及成功完成时会清空表单；成功后清理旧身份并要求重新登录。
6. ADMIN 用户管理使用真实 `items/total/page/page_size` 分页，支持创建和编辑显示名、平台角色、启停状态。用户名创建后只读；服务端“至少一个可用管理员”等错误原样显示，不伪造成功或自动重试写操作。
7. 移除了登录页硬编码开发账号与密码提示；不提供自动 bootstrap。
