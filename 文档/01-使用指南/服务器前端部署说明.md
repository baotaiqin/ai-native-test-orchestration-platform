# 服务器前端部署说明

## 范围与当前状态

本说明只覆盖 V1-D1/r1 新增的服务器前端镜像基础：Vite 多阶段构建、非 root nginx 静态服务、同源 API 反向代理、SPA 回退和容器静态健康检查。它不包含后端容器、数据库、中间件、TLS 证书或正式服务编排，也不代表 V1 已完成真实部署。

当前交付状态为：已实现部署文件，静态基本检查通过，真实镜像与环境行为待集中验收。当前不要启动 Docker、拉取镜像或执行正式部署。

## 镜像构建契约

集中验收阶段应从项目根目录使用以下精确命令构建；末尾的 `.` 是项目根构建上下文，不能改成 `frontend` 或 `deploy/server`：

```powershell
docker build --file deploy/server/frontend.Dockerfile --tag ai-test-frontend:v1 .
```

`deploy/server/frontend.Dockerfile.dockerignore` 是该 Dockerfile 的专用上下文白名单。镜像构建仅接收前端锁文件、必要的 Vite/TypeScript 配置、`index.html`、`src` 与本部署目录中的运行文件；`.env`、`.codex-validation`、Git/IDE 配置、依赖缓存、既有 `dist` 和项目其他目录均不会进入上下文。

构建阶段以 `frontend/package-lock.json` 执行 `npm ci`，再运行现有 `npm run build`。运行阶段使用非 root nginx，监听容器内 `8080`，不要求写入 `/etc`；PID 与所有 nginx 临时目录都位于 `/tmp/nginx`。

## 运行时网络边界

前端容器必须与后端服务加入同一个容器内部网络，并且后端服务的稳定 DNS 名称固定为 `backend`、HTTP 端口固定为 `8000`。nginx 将 `/api/v1` 及其子路径原样代理到 `backend:8000`，不剥离 `/api/v1` 前缀；API 错误直接返回，不进入 SPA 回退。

浏览器只访问前端同源地址：静态页面和 API 共用一个外部 origin。前端 nginx 不接受任意外部 upstream 参数，也不保存后端凭据。

## HTTP、缓存与健康检查

- `/assets/` 仅提供真实存在的哈希静态资产，响应带一年 immutable 缓存。
- `/index.html` 禁止长期缓存；其他前端路由通过 `index.html` 完成 SPA 回退。
- `/api/v1/runs/{run_id}/events/stream` 禁用代理缓冲与代理缓存，读写超时为一小时，以保留 SSE 流式传输。
- nginx 请求体上限为 `21m`：覆盖后端最大 `20 MiB` 文件以及 multipart 元数据开销，文件类型和实际大小仍由后端最终校验。
- `GET /healthz` 是不读取凭据、不访问后端的静态存活检查，只证明前端 nginx 正常响应。

## TLS 与外部代理边界

TLS 应在服务器入口层（负载均衡器、Ingress 或受管反向代理）终止，再通过受控内部网络把 HTTP 流量转发到前端容器 `8080`。入口层需要保留长连接和流式响应，且不能重新启用 SSE 缓冲。证书签发、域名、入口代理配置、可信代理名单与外部健康探测均属于后续正式部署任务，本包不提供示例密码、Token 或证书材料。

## Windows Runner 边界

Windows Runner 继续作为独立执行节点运行，不打入此前端镜像，也不由 nginx 启动或管理。Runner 与后端、消息队列和证据存储之间的连接、凭据及升级流程保持现有独立边界；本前端部署文件不改变这些契约。
