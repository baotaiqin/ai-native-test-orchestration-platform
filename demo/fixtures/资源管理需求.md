# 演示资源管理需求 V1

## 范围

本需求描述本机演示目标，不是测试平台本身。目标只监听本机回环地址，使用公开合成账号；资源和会话保存在当前进程内，重启后清空。所有示例均不包含真实个人信息。

## 登录与会话

### 登录

- 用户使用演示账号登录，正确凭据返回 HTTP 200、`data.token` 和用户名，同时设置 HttpOnly、SameSite=Strict 的会话 Cookie。
- 错误用户名或密码返回 HTTP 401，不创建有效会话。
- Bearer Token 或 `demo_session` Cookie 均可用于后续认证；同时提供时 Bearer 优先。
- 会话有效期为 20 分钟。登出撤销当前会话；过期或已撤销凭据访问资源接口返回 HTTP 401。

### 页面

- 登录页提供用户名、密码和登录按钮。
- 登录成功后进入资源工作台；未认证直接进入工作台则返回登录页。
- 页面定位器可在验收控制下改变，但按钮“登录”的语义标签不变，用于测试平台的定位器失效与人工确认修复。

## 资源管理

### 创建

- 已登录用户输入资源名称，创建成功返回 HTTP 201、唯一正整数 ID 和规范化后的名称。
- 名称去除首尾空白后长度必须为 1～120；空名称、纯空白、超长名称或非字符串返回 HTTP 400。
- 支持中文名称。允许同名资源，每次成功创建具有不同 ID；同名不等于幂等，不应对创建请求自动重试。
- 未认证请求返回 HTTP 401，不创建资源。

### 查询

- 资源列表返回 HTTP 200 和 `items` 数组；没有资源时数组为空。
- 新建资源应能通过返回 ID 在列表中找到，名称与创建响应一致。
- 当前演示实例只有一个合成账号，不据此宣称支持多租户隔离。

### 删除和清理

- 使用创建响应中的精确 ID 删除资源；成功返回 HTTP 200 和 `deleted=true`。
- 删除后列表中不再包含该 ID。
- 对不存在的整数 ID 再次删除返回 HTTP 404 和 `deleted=false`。
- 验收结束只清理本用例创建的 ID，不批量删除其他验收数据。

## 异常与可观测性

- 非法 JSON 或超出 64 KiB 的请求体返回 HTTP 400。
- 受控慢接口支持 0～30000 毫秒延迟；超出范围返回 HTTP 400。
- 受控重试接口对同一 key 的首次请求返回 HTTP 503，后续返回 HTTP 200，并给出尝试次数。
- 下载接口返回合成 CSV，要求有效登录态。
- 控制接口只用于本机验收，不作为对外业务 API；不得部署到公共网络。

## 验收链路与平台边界

1. 将本 Markdown 导入测试平台 Requirement，生成/审核测试建议并建立正式 Case 关联。
2. 导入同目录 `openapi.json`，核对登录、资源创建/查询/删除等 9 个操作及认证信息。
3. 使用 `resources.csv` 的 5 行样例验证正常、中文、去空白和非法名称；成功行必须清理其创建的 ID。
4. 通过平台正式 Scenario 完成登录→提取 Token→创建资源→提取 ID→列表断言→Cleanup。SQL 和 AI 断言、统一报告必须另接真实能力验证；内存演示目标本身不能证明这些平台功能已完成。
5. 通过平台 Web Case 验证登录、页面断言、定位器变更、自愈建议、人工 Reject/Accept、版本批准和重新执行。平台不得自动接受用户真实资产的 AI 建议。
